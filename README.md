# 1937·战略抉择｜AI 模拟辩论

这是一个纯前端、单页静态网站，用于展示围绕 1937—1938 年抗战战略选择的 AI 模拟辩论。

## 内容

- 六个辩论环节
- 24 段辩手发言
- 主持人串词与逐段播放
- 本段事实核查与参考资料
- 完整辩论记录与独立裁判报告

## 本地运行

直接用浏览器打开根目录中的 `index.html` 即可，无需安装依赖或启动服务器。

## GitHub Pages 部署

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
4. 等待 GitHub Pages 完成发布。

发布地址通常为：

https://jamesss-xh.github.io/1937-strategic-debate/

## 内容说明

本网站展示的是事先整理的 AI 模拟辩论稿，不是历史人物原话，也不是现场实时模型输出。页面中的史料、引文和链接应以原始档案及可靠出版物进一步核验；网站内容不应替代独立史料考证。
